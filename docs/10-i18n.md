# 10 — Localization

**Status:** approved · **Last updated:** 2026-11-08 · **Source:** [PROPOSAL.md](../PROPOSAL.md) §6 · **ADR:** [ADR-006](08-decisions.md)

English and Bahasa Melayu are both first-class. The agent-facing rules are in
[.claude/rules/i18n.md](../.claude/rules/i18n.md); this file is the policy.

## Language policy

| Item | Decision |
|---|---|
| Supported languages | `en-US` (English), `ms-MY` (Bahasa Melayu) |
| Default | `system` — follows the Windows display language. `ms-*` maps to Malay; everything else maps to English |
| Manual override | Settings ▸ General ▸ Language: System · English · Bahasa Melayu |
| Switching | Immediate, no restart. The tray menu and every open window re-render within one second |
| Fallback | A missing Malay key falls back to English and logs a warning |
| Spelling standard | Dewan Bahasa dan Pustaka (DBP) spelling and terminology |
| Malay variant | Malaysian Malay (`ms-MY`) |
| Date format (Malay) | `d/m/yyyy`, 24-hour by default, Malay day and month names |
| Date format (English) | Follows the Windows regional setting (`m/d/yyyy` or `d/m/yyyy`), 12- or 24-hour by user choice |
| Currency | `RM` in Malay mode, `MYR` in English mode; the user can set any code |
| User-written content | Stored exactly as typed. The app never translates a user's title or body |
| Time zone | `Asia/Kuala_Lumpur` (UTC+8) for JAKIM data regardless of the PC's zone. Reminders use the PC's local zone unless the user sets otherwise |

### How the switch works

The active Fluent loader lives behind an `RwLock` in `ot_i18n`, not a
`OnceLock`: a `OnceLock` can be set once, which is precisely what a live
switch is not. `ot_i18n::set_language` builds a loader for the new language
**before** taking the write lock — loading parses both catalogues, and doing
that under the lock would stall every string lookup in the app — then swaps it
in. Readers hold the lock only long enough to clone an `Arc`, never for the
lookup itself.

The two surfaces then follow differently, which is the part worth knowing:

- the **settings window** reads every string as it draws, so it is in the new
  language on its next frame and needs telling nothing;
- its **title** is set on the viewport rather than drawn, so it has to be set
  again;
- the **tray menu** was built once and belongs to Windows until it is rebuilt,
  so the switch rebuilds it.

`System` is resolved against Windows each time it is chosen rather than once
at startup, so a user who changes their Windows display language and comes
back gets what they expect.

Measured on the development machine: **2.4 ms** from click to both surfaces
switched, catalogue rebuild and tray menu included — against an exit criterion
of one second. The switch logs its own duration, so the claim is checkable on
a user's machine and not only on this one.

## The locale files

```
locales/en-US/omni_toaster.ftl     # embedded in the exe via rust-embed
locales/ms-MY/omni_toaster.ftl
OmniToasterData/locales/…          # optional user overrides, same file names
```

A user override is validated at load. A broken override is ignored with a
logged warning and the embedded text is used.

Keys are lowercase, hyphenated, and grouped by area:

| Prefix | Covers |
|---|---|
| `tray-` | The tray icon's menu and tooltip |
| `toast-` | Built-in toast labels and actions |
| `settings-` | The settings window |
| `prayer-` | Prayer names and prayer UI |
| `weather-` | Weather conditions and weather UI |
| `reminder-` | Reminder types, offsets, recurrence |
| `announce-` | Spoken announcement templates |
| `error-` | Errors and validation messages |
| `format-` | Date, time and number patterns |
| `update-` | The in-app updater |

## Rules

1. **Every user-visible string is a Fluent key.** A hard-coded user-facing
   string is rejected in review and by the CI lint.
2. **Never concatenate translated fragments.** Use Fluent variables, so word
   order can change per language.
3. **Never format a date or a number by hand.** `ot_i18n::format_datetime(dt,
   prefs)` is the only function that does it — the toast, the tray tooltip and
   the speech service all call it. There is no language argument: the day
   names, month names and am/pm words come from the active bundle, and
   `TimePrefs::for_language` carries the one genuinely language-dependent
   choice, 12- against 24-hour.
   Every substituted value passes through `text_with`, which strips Fluent's
   U+2068/U+2069 isolating marks. They are correct for mixed-direction text
   and, in two left-to-right languages, reach the user as stray boxes.
4. **Both files, same commit.** A key added to one and not the other fails the
   CI key-parity check.
5. **Edit locale files with the Edit tool, never a heredoc.** An unquoted
   heredoc expands `{ $variable }` and backticks, which silently mangles the
   message; the only symptom is a syntax-error count in the log and a failing
   parity check.
6. **Layouts are tested with the longest Malay string.** Malay text runs up to
   30% wider than English. A pseudo-locale build (about 40% longer) is used to
   find breakage early.

## What is localized, area by area

- **Settings, tray menu, built-in toast labels, validation messages, empty
  states:** fully localized.
- **Prayer names:** English uses Fajr, Dhuhr, Asr, Maghrib, Isha; Malay uses
  Subuh, Zohor, Asar, Maghrib, Isyak. Syuruk and Jumaat/Jumu'ah follow the same
  rule. **Settings always shows both names** — "Subuh (Fajr)" — so a user of
  either set can find the prayer. Prayer identifiers never change with
  language.
- **Weather:** Open-Meteo codes map to Fluent keys. No API text is ever
  displayed. Temperature is °C in both languages.
- **Templates:** a built-in default title and body exist in both languages. The
  template editor offers "Use default text" to restore the built-in text in the
  current language.
- **Speech:** generated from Fluent templates — for example
  `announce-time = Sekarang pukul { $hour } { $minute }.` — and spoken by a
  voice matched to the language tag ([specs/announcements.md](specs/announcements.md)).
- **User content:** never translated, stored as typed, with `authored_lang`
  recorded ([05-data-model-and-storage.md](05-data-model-and-storage.md)).

## Speech voice selection

In order: a voice whose language tag matches the active language · a voice in
the other supported language, with a visible hint that the announcement is in
the wrong language · no voice, in which case the announcement falls back to a
chime and the UI says why.

## Translation process

1. English is written first, with a translator context comment per key.
2. Malay is written against DBP spelling and terminology.
3. Both files are committed together.
4. Before the Phase 9 release, a Malay reviewer signs off and the sign-off is
   recorded in [CHECKLIST.md](CHECKLIST.md).

## Tests

Key parity · the formatter in both languages, including Malay day and month
names, 12- and 24-hour, and UTC+8 · voice selection order · the pseudo-locale
layout check · toast snapshots in both languages using the longest Malay
strings. See [.claude/rules/testing.md](../.claude/rules/testing.md).
