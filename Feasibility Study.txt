
# Omni TOaster

I want to develop rust desktop apps in windows where it resemble Windows Toast Notification.
Please help me to do proposal based on these requirements.

## Spec
- Project Name is Omni Toaster.
- Language : Rust.
Mode : Portable with settings folder in the same executable named "OmniToasterData".
- UI Framework : egui / slint/ eframe / iced / etc.
- Themes mode : System, Dark, Light. Dark is the dafult themes.
- Sit in system tray. when clicked/right click, some menu with some setting and open a detail settings page.
- Auto Startup when windows start. Auto start when apps crash with debug log saved for future debug.
- Size of toaster can be set by user. But put appropriate minimum and maximum size setting for toast notification.
- Toast Notification can be Rectangle, rounded rectange (can be set the rounded curve), etc.
- Toast Notification can have header with content. Content can have text and image upload/set by user.
- Toast Notification can be set color, transparent level, glass look, etc.
- Toast Notification In and out presentation can be choose by user. (Slide from right, slide from bottom, genie from bottom, pop out, drawer, appear, dissolved, glow, alpha to solid, etc.
- Toast Notification display duration can be set by user. Make a appropriate minimum and maximum duration settings.
- Apps can detect current user location or user can set its own location.
- These location data will be use for Azan Prayer Notification and Weather Notification.
- Type of notification includes Azan Prayer Reminder, Weather change reminder, Event reminder, Task reminder, Aniversary reminder, Fatigue reminder, Timer reminder, Alarm reminder, etc.
- Reminder time can be set on the time, 1 day before, 1 week before, 2 days before, 1 hour before, 15 minutes before and other time user can set. And can be snooze to remind again in 5 minutes, 1 hour, 1 day, etc, and so on.
- Time announcement with voice - Can be set every hour, mstart of the day, etc.
- For azan prayer, user can set/upload every audio for every prayer time.
